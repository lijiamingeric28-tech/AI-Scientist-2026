问题与愿景

把数周的文献苦力，交给一条智能体流水线。

科研数据散落在星表、论文与补充材料之间：字段命名不一、单位各异、可信度未知。 传统流程要靠研究者人工检索、阅读、誊抄、核对数百篇文献。 AstroQuery AI 把这一切交给智能体，只留下一个最关键的问题 —— 提取到的每一行数据，质量是否可信？清洗依据是什么？

异构来源

VizieR 星表、ADS 论文、CDS 补充材料，每个来源的字段、单位、精度都不相同，人工对齐反复试错。

人工誊抄

数值埋在 PDF 的表格与图谱深处，逐篇阅读、誊抄、核对——上百篇文献，动辄耗费数周。

质量不可信

拿到一行数据却无法回答：它被清洗过吗？依据是什么？多来源数值冲突时，该相信谁？

快速开始

四条命令，跑通全流程。

Python 3.10+ · 一条查询即可完整走完检索、提取与质检。

STEP 01

克隆并安装

git clone https://github.com/lijiamingeric28-tech/AI-Scientist-2026.git cd AstroQuery_AI pip install -r requirements.txt
STEP 02

配置密钥

AstroQuery_AI/.env DASHSCOPE_API_KEY（必填）
ADS_API_TOKEN · UNPAYWALL_EMAIL（可选）
STEP 03

构建前端

cd frontend && npm install && npm run build 仓库不含构建产物，启动 Web 界面前必须执行
STEP 04

发起查询

python -m astroquery_ai "M31 的距离和金属丰度" 或 python -m web.desktop 打开内置桌面窗口
AstroQuery_AI — shell
# Web 界面（浏览器 / 桌面内置引擎）
python -m web.main        # http://127.0.0.1:8000 · SSE 实时流 + 事件回放
python -m web.desktop     # 桌面窗口 · WebView2 · 关窗即停

# 质量验证（370 项全 mock 离线测试）
python -m pytest tests/ -m "not network"
