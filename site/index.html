异构来源

人工誊抄

质量不可信

why astroquery

为什么是 AstroQuery AI

🧬

PropertySpec 系统中枢

SIMBAD/otype + RAG 性质库 → 字段白名单 + 标准单位表，三路提取路径归一。

三路并行检索

27 个 VizieR 星表（LLM 列名归一）+ ADS 论文 + Unpaywall PDF + CDS 补充材料。

VLM 多模态提取

三层动态工具

Cohen's d 统计冲突

效应量替代相对差异法（含 95% CI）——组内方差小时传统方法漏报，这里不会。

quickstart

3 条命令跑起来

1

安装

pip install -e .
2

配置 API Key

AstroQuery_AI/.env
DASHSCOPE_API_KEY（必填）· ADS_API_TOKEN · UNPAYWALL_EMAIL（可选）
3

启动

python -m astroquery_ai "M31 的距离和金属丰度"
或 python -m web.desktop 打开内置窗口 
# CLI（一条查询跑全流程）
python -m astroquery_ai "M31 的距离和金属丰度"

# Web 界面（浏览器 / 内置引擎窗口）
python -m web.main        # http://127.0.0.1:8000
python -m web.desktop     # 桌面窗口（WebView2）

# 测试（370 项全 mock 离线）
python -m pytest tests/ -m "not network"
