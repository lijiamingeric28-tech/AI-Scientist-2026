# 新样例与科学库加载优化实施计划

Spec: docs/superpowers/specs/2026-11-13-sample-startup-loading-design.md。用户已授权实施。使用SDD独立任务与评审；不提交或推送，不切换当前分支，不丢现有修改。暂存目录验证后按原文件哈希回写；真实任务测试只用隔离副本。

## Tasks

- [x] 1 基线/保全：当前代码快照、SQLite备份、用户JSON、准确7样例列表；建立冷启动/导入/资料读/重启和热读取可重复基准；不调用真实模型。
- [x] 2 科学编译：失败测试后一次索引构建、投影准确复用、同服务同版本加载单飞；不跳AST/BDD/引用/许可校验。全部上下文输出及manifest/绑定hash严格一致，损坏和依赖变化拒绝，失败可重试；5进程测量。
- [x] 3 样例导入：按样例单飞和有界批量写，事务/外键/哈希/同ID用户优先；失败及并发测试；7份导入并比较原始行及对象哈希。
- [x] 4 后端读索引：现有UI缓存增加交付头、资料与精确详情索引，准确版本/协议、原子构建和失败回退；所有普通命中0整包解码；summary投影与ETag动态时点隔离。大快照并发单飞。导出不读缓存。相关回归和大样例基准。
- [x] 5 前端读取：32页/8MiB有界缓存、250ms搜索、取消与失效、静态恢复及轻量总结刷新；隐藏0请求；首屏必要三读取，状态保留及主题不变；真实React/HTTP边界回归。
- [x] 6 整合验证：任务评审+独立最终审查、修复；前端全套/build、后端离线全套；30次暖/API/浏览器性能和首次成本分解；受控回写/重启、真实数据哈希对照，留主服务运行，报告不足。

最终结果与不足见 `docs/performance/2026-11-13-sample-startup-loading.md`。科学校验和暖读取达到目标；最大样例首次完整导入及建索引 13.616 秒，未达到 8 秒目标。已报告原始分段耗时，未减少数据或放宽校验。跨进程已有索引在主服务实测首轮三读取共 1.086 秒；这不是 30 次独立重启的 P95。

## Shared interfaces / ownership

科学任务仅registry加载/编译/投影及其测试；后端任务仅delivery/result_views/material_workbench/UI索引/results路由及其测试；前端任务仅MaterialWorkbench/API缓存辅助及其测试。Root负责PublishedDemos、基线/基准、协调/集成、App层必要读取清理。其他范围先协调。

后端保持现有GET/响应，workbench资料详情增加projection=summary，返回delivery_id/delivery_revision/snapshot_ref及summary。默认详情含summary行为保留。前端轮询仅此轻量投影。动态总结/历史截止不得作为静态永久缓存；普通写入后现有全局失效必须连带清除资料缓存。

## Review focus

准确输出与缓存对象不能被消费者修改；同ID不同版本不混；历史捕获后事件/总结不可见；索引损坏/磁盘失败不能空白成功；跨页全匹配导出不得变当前页；缓存不得成为资格或导出授权。避免把已有锁/缓存/懒加载误称新增或以放宽检验加速。
