## Locked contracts

Filters: keyword, category, source=all|builtin|user|override, preferred_only, property_ids=comma-separated, sort=name|relevance|preferred|updated, offset, limit. List summary request adds view=summary. List response preserves {items,total}, adds revision/offset/limit. Entry summary preserves existing fields; detail is flat entry with revision and relations={properties,base,derived,base_unavailable} when available.

GET /api/knowledge/summary returns {total,matched_total,revision,categories:[{id,label,color,count}],sources:{builtin,user,override},properties:[{id,label,count}]}. Categories are facets under all common filters except category itself. Corpus total is separate from matched total.

GET /api/knowledge/graph adds view=overview|category|focus, focus_id, limit(default80, max200 total nodes). Bare legacy request preserves legacy graph format. Returns {nodes,edges,categories,meta:{total_entries,matched_entries,shown_entries,node_count,truncated,view,revision}}. Nodes have kind=category|property|entry|aggregate, id,label,category,is_property,count where applicable; category nodes expose category, property nodes expose property_id. Edges have id/source/target/label/relation_type/provenance. All projected data is real and bounded, search can reach every effective entry. Exact explicit/curated aliases and base_id create confirmed edges; unsupported approximate matches do not.

Write bodies support expected_revision (DELETE uses query). Create/update return canonical flat entry with revision/library_revision; preference and restore return {success,id,entry,revision,library_revision,...}; DELETE returns {success,id,action,revision,library_revision}. Restore uses POST /{id}/restore. Missing revisions in old files=0. Commit memory only after successful atomic persistence. Conflict409 keeps UI draft. Builtin deletion hides including overrides; restore clears hidden/override/preference. User deletion does not cascade derived entries. Preserve IDs and existing source merge semantics.

Frontend child contracts preserve current callback names. ListView adds mode=cards|table,onModeChange,selectedId,total,offset,limit,onPageChange,onPageSizeChange,sort,onSortChange,loading,readOnly,pendingIds. Editor onSave(payload,mode) returns a promise; editor stays open with draft on rejection, closes only after success. Drawer adds loading/readOnly/pending,onFocus,onShowAllRelations; item.relations contains full associations. GraphView adds onEnterCategory,onEnterProperty,onFocus,onShowAllRelations,onBack,canGoBack,sceneKey,viewState,onViewStateChange; category/property navigation never opens entry CRUD. Root graph uses new .kg-* CSS, workspace .kwb-*, reading .kr-* to avoid shared stylesheet edits.
