# AstroQuery AI GitHub Pages 视觉改造设计

## 目标

在不改变 AstroQuery AI 后端、数据产物和 GitHub Pages 静态部署方式的前提下，将现有落地页改造成更具科研叙事感的深色电影式页面。页面以项目 `icon.png` 的“A 核心 + Q 轨道 + 紫色星云”为视觉母题，重点强化首页星空、滚动形变、可追溯数据表达、五阶段横向卡片和中文排版。

参考页面是 OpenAI GPT-6 Astra 发布页，但只借鉴其超大标题、克制导航、连续叙事、深色留白和图文节奏；不复制其品牌、文案、素材或页面结构。

## 已确认边界

- 页面保持纯静态 HTML、CSS 和原生 JavaScript，不引入前端框架、构建工具、第三方 CDN 或运行时依赖。
- 不动态读取用户本地 CSV，不调用 AstroQuery AI 后端，不调用远程 API，也不把真实任务数据打包进页面。
- “每一行数据都有据可查”使用静态结构示例和仓库内真实字段概念表达，不伪造论文 DOI、页码、数值或实验结果。
- 保留 GitHub Pages 当前从 `site/` 和 `assets/` 组装站点的部署方式。
- 保留当前工作区已有的页面重构、字体文件和其他未提交改动；只在与本次页面相关的文件上做增量修改。
- 所有运动效果支持 `prefers-reduced-motion`，并兼顾键盘、触摸屏和窄屏浏览。

## 方案比较

### 方案 A：继续增强现有单屏 Canvas

只增加粒子数量、亮度和鼠标视差，改动小，但单个 100vh Hero 没有足够滚动距离表现“聚拢 → 变形 → 爆开 → 两侧流动”的完整过程，星空与正文也会很快脱节。

### 方案 B：Sticky Hero + 可逆粒子形态 + 沉浸式横向卡片（采用）

将 Hero 扩展为约 180vh 的滚动舞台，内部画面保持 100vh sticky。所有粒子位置由当前滚动进度即时计算，因此向下和向上滚动都能可逆重放。五阶段能力区继续使用原生横向滚动和 scroll-snap，但增加阶段导航、证据链和更完整的图文层级。

该方案能覆盖全部需求，同时保持无依赖、部署简单、移动端可降级。

### 方案 C：引入 WebGL/Three.js 与专业轮播库

可以实现更复杂的三维粒子和物理拖拽，但会增加依赖、包体、兼容性和维护成本，也不符合当前 GitHub Pages 的单页轻量结构，因此不采用。

## 页面结构

### 1. 固定导航

- 使用真实 `AstroQuery_AI/icon.png` 作为品牌图标，复制为站点内的 `site/assets/icon.png`，保证本地预览与 Pages 部署路径一致。
- 导航使用半透明深色材质；进入正文后提高背景不透明度。
- 保留愿景、演示、能力、快速开始和 GitHub 入口。

### 2. Sticky Hero 星图舞台

Hero 外层提供约 180vh 的滚动距离，内部 `.hero-stage` 固定在视口中。舞台包含 Canvas、柔和星云底色、标题文案、操作按钮和滚动提示。

粒子分为四层：

1. 背景远星：低速漂移和轻微闪烁，形成密度与纵深。
2. 星云旋臂：紫、暖橙、冷白、青色粒子构成缓慢流动的椭圆星云。
3. A 字星群：沿两条斜边和横杠采样，形成清晰但不生硬的发光 A。
4. Q 轨道：椭圆星环、右下尾迹和巡航亮点构成 Q，环绕 A 运动。

滚动进度分为连续的三个区间：

- `0.00–0.30`：维持 A/Q 星图，鼠标控制轻微视差、倾斜和旋转。
- `0.30–0.68`：星图压扁、旋转加速，粒子出现横向拉伸和吸积形变，标题逐渐收缩淡出。
- `0.68–1.00`：粒子从中心向左右分流，在画面两侧形成持续纵向漂移的星带。

滚动进度直接由 Hero 的位置计算，不记录“播放完成”状态。因此反向滚动会按同一路径恢复，动画天然可重复。

Canvas 使用预渲染辉光精灵、限制设备像素比、按视口面积控制粒子数量，并只在 Hero 可见且页面未隐藏时运行。减少动态偏好下保留一帧静态 A/Q 星图，取消视差、爆炸和循环运动。

### 3. 愿景与演示

- 保留现有问题卡片和演示 GIF，统一标题层级、留白、边框和背景材料。
- 通过重复触发的 reveal 状态让区块在进入视口时出现，离开后复位。
- GIF 保持懒加载，并提供准确替代文本。

### 4. “从一句话，到黄金数据”横向叙事

能力区将“每一行数据都有据可查”的承诺与五张架构图融合为一个连续组件，而不是拆成单薄的独立段落。

组件包含：

- 顶部静态证据链：自然语言问题 → PropertySpec → 来源与原文定位 → 质检/修改留痕 → 结构化交付。
- 五个横向卡片：总览、规范中枢、检索提取、质量管线、成果交付。
- 每张卡片左侧为阶段编号、标题、解释和输入/输出；右侧为对应架构图。
- 每张卡片底部提供 2–4 个静态“证据锚点”，使用仓库真实概念，例如 `source_id`、`page + bbox`、`raw_quote`、`modifications`、`traceability` 和 `quality_summary`。
- 当前卡片由阶段导航、进度条和 `01 / 05` 计数共同显示；支持按钮、键盘左右键、触摸原生滑动和鼠标拖拽。
- 图片可进入 Lightbox；焦点、Escape 关闭和左右方向键导航保持可用。

### 5. 静态溯源样例

卡片区域内展示一条明确标注为“输出结构示例”的静态记录，说明一行数据可包含：

- 标准字段和值/单位；
- 来源类型和 `source_id`；
- 论文页码、定位框或星表行列位置；
- 原文摘录；
- 清洗前后值与规则/智能体决策；
- 最终质量摘要。

示例只展示字段结构与状态，不写未经仓库证据支持的 DOI、论文页码或天体数值。相关说明链接到仓库 README 和技术报告，便于访问者核对设计依据。

### 6. 数据指标与快速开始

- 保留 README 已陈述的 370 项离线测试、27 个 VizieR 星表、9 个智能体子图、99 类 PropertySpec、294 条领域规则和 6 维质量评分。
- 指标下方增加“依据”链接，统一指向仓库 README 或技术报告；不把这些指标描述为实时数据。
- 快速开始继续使用当前四步说明和终端示例，仅调整视觉密度和响应式排版。

## 字体与视觉系统

- 中文正文和标题使用已自托管的 MiSans 400/500/700；代码和数据使用系统等宽字体。
- 页面显式注明使用 MiSans，以符合字体许可中的署名要求。
- 标题使用更紧的字距和较短行高，正文使用较宽松行高；数字采用等宽或 tabular numerals，强化科研仪表感。
- 主背景为近黑色，品牌色取自图标的紫色、暖橙和冷白；青色只用于状态与数据验证，不大面积铺色。
- 卡片使用细边框、低透明渐变和局部辉光，不使用强烈玻璃拟态堆叠。

## 交互与状态

### Reveal

IntersectionObserver 对每个 reveal 元素持续切换 `is-visible`，离开视口时移除；不使用 `unobserve`，不保存已播放标记。元素可通过 CSS 变量设置交错延迟，离开时立即复位。

### Carousel

活动索引由卡片中心与容器中心的距离计算，不依赖固定卡片宽度，避免响应式宽度变化后计数错误。按钮、阶段标签和键盘都调用同一个 `goTo(index)`；拖拽结束后吸附到最近卡片。

### Lightbox

打开时保存原焦点，关闭时恢复；背景滚动锁定；图片加载失败时显示文字说明而不是空白对话框。

### Starfield

所有运动由时间、指针目标和滚动进度驱动。指针离开窗口后平滑回中；页面隐藏或 Hero 离开视口时暂停 requestAnimationFrame，恢复时重置时间基准，避免巨大时间步长。

## 错误与降级处理

- Canvas 不可用时显示 CSS 星云背景和真实 icon，不影响标题、按钮和正文。
- JavaScript 不可用时横向卡片仍可原生滚动，导航锚点和所有正文仍可阅读。
- 图片加载失败时保留卡片文本、边框和替代文字。
- `IntersectionObserver` 不可用时所有 reveal 内容直接显示。
- 减少动态模式下禁用平移、视差、闪烁、自动漂移和顺滑滚动。
- 窄屏降低粒子数量、辉光尺寸和 Canvas DPR，卡片切为上下布局。

## 文件变更

- 修改 `site/index.html`：结构、样式、静态文案、Canvas 动画、Carousel、Reveal 和 Lightbox。
- 新增 `site/assets/icon.png`：从 `AstroQuery_AI/icon.png` 复制的站点品牌资源。
- 新增 `site/tests/landing-page.test.mjs`：使用 Node 内置测试验证关键静态结构、无动态数据源、交互辅助属性、可重复 reveal 和 Hero/Carousel 关键代码契约。

## 测试与验收

### 自动验证

- 先编写并运行静态页面契约测试，确认测试因缺少新结构而失败。
- 实现后运行 `node --test site/tests/landing-page.test.mjs`。
- 用 HTML 解析/静态检查确认页面不存在本地绝对路径、动态 CSV 请求、未闭合关键结构和重复 ID。
- 检查 `git diff --check`，避免空白错误。

### 视觉与交互验收

- 1440×900：A/Q 星图清晰、星点数量充足，标题无遮挡，滚动完整经历三阶段。
- 390×844：标题和按钮不溢出，粒子密度降低，卡片上下排列且可触摸滑动。
- 向下、向上重复滚动：Hero 形变可逆，普通区块每次离开再进入都会重新播放。
- 鼠标移动：星图有克制的视差与旋转，指针离开后回中。
- 键盘：导航、Carousel、Lightbox 均可操作；焦点可见。
- 减少动态：页面内容完整，无大幅位移或持续闪烁。

## 完成标准

- 用户列出的星空亮度/数量、A/Q 造型、鼠标跟随、滚动变形与两侧爆开效果全部实现。
- 中文排版统一使用可商用、自托管并注明来源的 MiSans。
- “一句话到黄金数据”、五张架构图和每行可追溯承诺形成一个完整横向叙事组件。
- 所有展示内容为静态内容，不读取 CSV、不接后端、不发送数据请求。
- 页面滚动动画可重复触发，且支持响应式、键盘和减少动态模式。
- GitHub Pages 现有部署方式可以直接发布新增资源。
