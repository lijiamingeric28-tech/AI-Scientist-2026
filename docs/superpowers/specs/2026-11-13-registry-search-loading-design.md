# 规范工作台分类搜索与按视图加载

用户已授权继续完成上轮提出的两项优化：给性质分类增加搜索，按当前视图读取数据并保留搜索/筛选，沿用现有设计与系统配色。桌面横屏优先。

- 分类控件复用原生选择器和现有表单样式，上方增加本地名称/标识搜索，展示匹配数量与无结果状态；过滤候选不改变已选值。侧栏和性质编辑表单复用同一组件。使用当前规范版本的完整分类目录，切换图谱/卡片/表格保留分类搜索及已选条件。
- 目录统计按版本缓存；筛选统计继续遵循现有服务端语义。未筛选时目录与统计共用一次读取。编辑器复用同一完整目录缓存。分类输入只在本地筛选候选，不发送性质检索请求。
- 图谱模式只读取图谱，矩阵只读取当前卡片/表格分页列表。隐藏视图停止发起请求，切换时取消未完成请求；过期响应不能覆盖或写入当前缓存。
- 记录数量使用当前筛选统计，不依赖隐藏列表。加载、错误、只读状态只由必要统计与当前视图决定。重新读取/写入继续统一失效全部缓存；缓存按版本、筛选和分页隔离。
- 保留关键词、类型、分类、来源、状态、排序、选中条目；返回相同矩阵模式保留分页。新组件不增加独立色板、依赖或后端接口，不修改规范内容或历史任务。

方案选择：在原生选择器旁增加搜索，比替换为自制浮层列表更贴合已有表单与键盘操作；共享版本目录避免增加逐字搜索请求；在既有读取 Hook 中门控当前视图，保留已有缓存及版本语义。

验证：单元测试覆盖分类名称/ID/别名式多词搜索、空结果、已选值保留及大目录；真实 React Hook 的浏览器回归覆盖初始请求数、同条件缓存复用、快速切换取消、旧响应、刷新失效、版本隔离、隐藏视图错误、筛选与选中状态保留；前端全量测试和生产构建。
