# 功能整合后的加载与正确性验证

2026-11-13。远端参考版本 `3057b71`；本地参考 `46dd916` 及未提交功能。当前结果保留在本地工作区，未提交或推送。

## 加载链路

- 规范工作台首次只读目录与当前视图；分类候选搜索在本地进行。统计、版本历史和编辑能力按用途拆分，切换保留搜索、筛选、页码和选中对象。
- 公共 GET 按完整请求身份合并；消费者独立取消，最后一个消费者取消才中止底层请求。条件读取不修改原始 ETag 缓存对象。
- 对话刷新使用同一快照的一次组合读取。临时预览按可见内容版本刷新，不因无关事件重新搬运结果。
- 普通记录页读取 50 条及完整结果的统计与筛选目录。详情按准确 ID 读取，重复归档成员不需要下载全库。科学图表的完整分析数据只在打开相应视图时读取。
- 新资料工作台维持资料、记录与图像各自的分页。隐藏资料详情停止轮询、取消未完成读取，并保留已读页面；迟到结果不能触发隐藏子页面读取。
- 新的资料选择导出与原有“全部匹配记录”导出均保留。后者由服务端解析完整筛选与排除集合，不以浏览器当前页代替。

原始优化前后对照见 [加载速度与数据流转优化验证](2026-11-13-loading-speed-data-flow.md)。未通过裁剪公式、单位、误差、原文或科学证据取得加载成绩。
