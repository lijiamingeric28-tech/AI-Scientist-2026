# 加载速度与数据流转优化验证

后续功能整合的最新测试、主服务复测及数据保全结果见 [功能整合后的加载与正确性验证](2026-11-13-fusion-loading-verification.md)。下文保留原始优化前后固定条件基准。

日期：2026-11-13。范围为加载、展示和读取；科研计算、规范发布、历史载荷及原始导出格式继续由原有权威流程处理。

## 已实施的数据依赖

| 入口 / 操作 | 现在读取什么 | 移除或延迟的读取 |
| --- | --- | --- |
| 首页 | 配置、当前任务目录 | 演示目录延迟至打开演示样例 |
| 直接进入规范工作台 | 一份完整类型/分类目录及统计、当前图谱 | 不再重复读无筛选统计；版本历史、编辑器、能力清单延迟 |
| 规范工作台搜索 / 筛选 | 轻量统计及当前图谱或当前列表页 | 隐藏视图不请求；分类候选搜索在本地完成 |
| 版本选择 / 发布历史 | 精简工作区及发布目录 | 列表不再带所有操作、校验正文和执行清单 |
| 规范新增 / 编辑 | 当前准确版本的完整编辑目录 | 完整科学能力只在编辑时读取；按版本复用 |
| 知识库 | 完整物理量目录一次、轻量筛选统计、当前视图及分类目录 | 编辑、分类管理、关联管理代码按打开操作加载 |
| 普通任务对话 | 同一事务中的状态与展示，使用同一游标 | 移除一次重复状态/展示读取；展示事件增量复用 |
| 回放 / 旧档案 | 原有准确时点的读取与兼容适配 | 保留旧协议回退；不把最新状态套到历史 |
| 临时预览 | 当前内容版本的一页，及该页证据相关解释、派生和文档资料 | 事件日志变化不重读未变预览；不再解码全任务测量/派生集合 |
| 结果记录首屏 | 交付头、一页 50 条摘要及全局计数、筛选目录 | 不自动下载后续页、来源正文、质量正文和图像 |
| 结果详情 / 来源 / 图像 | 指定交付修订与准确 ID；来源关联记录另行分页 | 不先下载整个资源集合再查单项 |
| 科学图表 | 用户打开时读取完整、精简的分析投影 | 普通表格不下载图表全量数据；图表不抽样、不改数值 |
| 导出 | 当前页为明确 IDs；全部匹配为服务端过滤协议及排除集合 | 不为了选择全部而向浏览器下载整库记录；不把当前页当作全部 |

共享 GET 使用规范化键、各消费者独立取消和 ETag/304；成功写入失效缓存。失败和带密钥的配置草稿不进入持久缓存。展示缓存不是导出授权来源。

## 版本和正确性

- 读索引位于独立可重建的 `runtime-data/cache/ui-read-models.sqlite3`；按来源任务、交付、修订、内容哈希、资源及协议绑定。首次读取时事务性构建，不将 UI 缓存构建加入科学发布事务。
- 服务端先校验准确任务和交付修订，再允许返回 304。导出仍使用权威快照重新解析筛选，并保留旧修订限制、并发检查和幂等行为。
- 详情中的记录、来源、资料和质量缓存均按任务、交付和修订精确复用。历史回答跳转不会用同 ID 的当前版本替换旧值。
- 搜索、年份排序、重复归档、修改标记和总数针对完整结果。真实论文的嵌套年份保持原有空值回退顺序。
- 分类目录、公式、单位、误差、上限和科学来源没有为性能静默截断。用户自定义性质、原值保留及未能转换的原因继续经过既有回归。
- 明暗及系统配色读取逻辑、布局变量和交互样式保持原样；新增加载反馈复用现有组件和主题类。

## 浏览器测量

保留优化前生产资源，与优化后生产资源在同机、相同后端数据上比较。每组 30 次；首组比较的完成条件包含图谱数据与全部 1411 个分类候选，不仅是弹层外框。

| 场景 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 直接进入规范工作台请求数 | 8 | 4 |
| 冷前端资源导航 P50 | 1267.8 ms | 769.2 ms |
| 冷前端资源导航 P95 | 2501.9 ms | 1198.2 ms |
| 已打开设置页进入工作台 P50 / P95 | 未测 | 308 / 432 ms |

冷导航测试对静态资源使用 `no-store`，后端科学预检已完成。暖进入耗时包含自动化点击及轮询开销。两百节点图谱实测绘制 P95 为 3.10 ms；静止两次读取的累计帧数均为 48，无持续绘制。截图为 1280×720，无整页横向溢出。

另补充严格就绪检查：等待 Worker 布局完成、`.kg-loading` 消失，再等待两帧。最新构建冷前端资源导航 30 次 P50 / P95 为 **708.8 / 942.1 ms**；从设置暖进入 30 次为 **360 / 450 ms**。全部分类均保留，未用空画布或缩减节点预算计时。该补充组单列，不替换前后同条件的首组对比。

首次进程科学库预检仍可能需要约 20 秒，另行记录，不计入暖读取成绩；本轮没有绕过预检。多进程可能重复构建同一 UI 索引，但只会事务性发布完整结果。

## 接口和合成数据测量

同一份真实数据，每场景首次读取单列，再取 30 次暖读取。最终接口组在上一轮全量回归结束后采样，减少测试进程争用影响；7 组均 31 次成功、无失败。传输量为未压缩 JSON 字节，不包含传输层压缩效果。

| 场景 | 原 P50 / P95（ms） | 新 P50 / P95（ms） | 原 / 新字节 |
| --- | ---: | ---: | ---: |
| 规范完整目录 | 392.32 / 701.34 | 120.21 / 185.79 | 4,144,420 / 358,408 |
| 规范筛选统计 | 375.16 / 1537.48 | 36.25 / 71.64 | 3,848,058 / 695 |
| 知识库统计 | 117.96 / 337.16 | 40.81 / 92.80 | 329,305 / 2,012 |
| 规范卡片页 | 46.10 / 154.83 | 38.60 / 108.87 | 209,951 / 209,951 |
| 规范图谱 | 44.98 / 124.43 | 42.99 / 84.52 | 169,525 / 169,525 |
| 对话刷新 | 369.35 / 1445.09 | 171.92 / 437.52 | 438,403 / 169,320 |
| 结果页，limit=50 | 58.50 / 157.17 | 25.24 / 62.52 | 118,590 / 149,701 |

对话每次刷新从 2 个请求减为 1 个。结果页增加完整筛选目录、全局统计和紧凑来源标签，因此单页字节略有增加；正常首屏不再为了表格下载后续页和全部来源正文。没有通过删除科学字段或改变完整导出范围降低数字。

5000 条隔离合成记录，30 次服务读取加序列化：索引暖页 P50 / P95 为 30.98 / 35.82 ms；保留现有已解码快照缓存、执行完整行投影的对照为 60.33 / 69.01 ms。首次索引构建 323.89 ms，50 行及全局目录 44,278 字节。这是同一行契约的服务层比较，不是旧产品浏览器成绩。并行回归负载下复跑为 33.40 / 51.34 ms，对照 66.64 / 82.51 ms。

复现命令，在 `AstroQuery` 目录执行：

```powershell
.venv\Scripts\python.exe tools/benchmarks/loading_speed.py --samples 30 --optimized --output scratch/loading-speed-api-after.json
.venv\Scripts\python.exe tools/benchmarks/result_read_index.py
```
