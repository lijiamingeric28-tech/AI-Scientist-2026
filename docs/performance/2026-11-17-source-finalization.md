# 源码与十例案例库更新

本次更新源码和内置真实案例，不创建新的 Release，也不替换此前已发布的 Windows 二进制。

## 科学处理修正

线性无量纲量不再因原文未打印单位而一律被 `source_unit_missing` 拦截。接纳仍须同时满足：批准性质的输出口径为线性无量纲量、原件中的对象和物理量精确匹配、独立核验通过，并有可定位的原文依据。原报单位继续保存为空，执行单位 `1` 单独记录其声明和依据。

此规则不把成员星系的红移当作星系团整体红移，不将速度字段改成红移，也不允许缺单位的有量纲测量通过。已有历史交付不重写。离线复核使用已保存原件和响应，不产生新增模型调用。

本次提交同时收录此前已验证的缓存费用记录、表格分组处理、洞察容量处理及自动/手动标题修正。详情见同目录 2026-11-16 的三份性能和验收说明。

## 案例发布方式

资料总结和性质洞察分别保留检查点。连接超时、传输失败和局部文件访问失败按当前资料或性质记录，既有有限重试额度不变；单份资料失败不会取消其他资料，也不会阻断后续性质洞察。暂停、任务删除、过期租约和科学快照变化仍按原门禁停止。

完成卡片的各性质记录数取自正式交付的结果列表汇总，使用全量统计而非当前分页长度，也不再读取处理过程中的历史测量计数。资料数与结果页统一为去重资料数。点击完成卡片中的性质会清除旧搜索和其他筛选，直接查看同一范围。此展示修正仅发生在前端，不改写历史科学数据。

保留 SN 2014J 主案例和九个代表性查询。目录顺序、交付修订、记录数量和性质名称见根目录 README 及 `frontend/public/demo-catalog.json`。每份历史只发布固定交付、科研证据和回放所需记录；账户设置、密钥、计费账本和模型调用原文不随案例发布。

确认查询时冻结的性质知识上下文随对应案例保存，保留原始内容哈希，避免新安装环境在追问或核对定义时依赖本机历史库。

未选中的旧演示从仓库发布资源中移除。本机个人历史、原始数据及暂停任务保留。案例中局部错提、未决审核和洞察缺口保持真实状态，不补造结果，也不以十例展示声称已验证全部 100 类天体的正确率。

## 验证范围

源代码回归、前端测试和构建采用真实处理入口；案例另外在独立、无凭据的运行目录中验证固定交付、来源、回放和导出接口。科研结果的可查看性不代表每条测量都已通过人工复核，使用时仍须检查原报、条件与引用。
