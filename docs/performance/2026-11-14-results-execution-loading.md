# 数据结果与执行明细加载优化验证

范围：质量与处理的完成情况、处理记录、覆盖与差异；执行全景、事件/异常、作业及详情；资料目录可拖动的返回顶部按钮。

## 实现

- 完成情况复用经内容哈希核对的封存评分，不等待分析记录。
- 审计报告使用独立的 `audit/2` 可重建投影，键包括准确交付、修订、内容哈希及相关报告/阅读事实/人工判断身份。每次命中前仍校验交付和回放范围。首次缺失共享一次构建，损坏或磁盘失败保留正确读取路径。
- 处理记录在全量范围筛选后分页，每页20条；只读取本页关联测量。覆盖页读取全部29项相关人工判断，不再先下载4137项全量处理记录。旧接口返回内容不变。
- 执行视图共享经数据库事实签名验证的重建，内存上限24MiB/8项；并发合并、同游标修复失效、精确历史、返回副本隔离均有测试。
- 前端执行分页缓存上限4MiB/32项，隔离任务、游标、筛选及刷新版本；搜索250ms防抖，取消过期读取。审计分页复用现有8MiB/32页缓存。
- 资料页返回顶部为可拖动浮层，支持边界限制、缩放/容器变化后收回可见范围、Alt+方向键移动、拖动抑制点击、正常点击回顶。新样式仅使用系统语义颜色。
