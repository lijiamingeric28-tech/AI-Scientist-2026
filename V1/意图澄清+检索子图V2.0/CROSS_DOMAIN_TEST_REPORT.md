## 🔍 关键发现

### 1. 天文学全面领先 ⭐

- **成功率最高**: 78.1%
- **下载速度第2**: 2.6秒/篇
- **数据量最大**: 324篇（占总成功数35.0%）
- **所有查询均优秀**: 3个查询成功率都在73%以上
- **原因**: 社区开放文化、arXiv普及率高

### 2. 材料科学表现最差 ⚠️

- **成功率最低**: 30.6%
- **催化剂成功率仅18.4%**（全部查询中最低）
- **投入论文最多**: 409篇（最多），但成功125篇（最少之一）
- **原因**: 
  - Nature/Science/ACS等顶刊付费墙严格
  - 工业应用领域，商业保护多
  - 预印本文化不普及

### 3. 医学与材料成为"困难学科"

- **医学**: 40.4%成功率
  - 癌症免疫治疗仅33.1%
  - 顶级医学期刊付费墙严格
  
- **材料**: 30.6%成功率
  - 催化剂领域最困难（18.4%）
  - 二维材料也仅30.8%

### 4. 物理引力波一枝独秀

- **引力波成功率85.4%**（单查询最高）
- **原因**: LIGO等大型科学项目强制开放数据政策
- 验证了"大科学项目推动开放获取"的假设

### 5. 下载速度与成功率呈弱正相关

- **天文/计算机**: 高成功率 + 快速度 = arXiv等预印本多，直接命中
- **医学/材料**: 低成功率 + 慢速度 = 大量失败尝试消耗时间
- **例外**: 材料学科速度较快（3.8秒），因为很多源快速返回403/404

### 6. 学科间差异极其显著

- **成功率差距**: 78.1% vs 30.6% = **2.6倍**
- **下载量差距**: 324篇 vs 125篇 = **2.6倍**
- **单查询差距**: 85.4% vs 18.4% = **4.6倍**

## 💡 结论与建议

### 主要结论

1. **开放科学文化是决定性因素**
   - 天文/物理(引力波): 开放数据 → 高成功率(78%+)
   - 材料/医学: 商业出版 → 低成功率(30-40%)

2. **Waterfall + Unpaywall策略有效但有限**
   - 总成功率52.4%，927篇论文成功
   - 在开放领域可达78%，但在封闭领域仅30%

3. **大科学项目推动开放获取**
   - 引力波(LIGO): 85.4%
   - 系外行星(JWST/Kepler): 76.5%

4. **学科特征深刻影响下载成功率**
   - 预印本文化 → 高成功率(天文、计算机、物理)
   - 顶刊主导 → 低成功率(医学、材料)

### 改进建议

#### 针对材料科学 ⚠️ 优先

1. **添加ResearchGate爬虫**（许多材料学者分享预印本）
2. **机构仓储支持**（MIT DSpace、Caltech等）
3. **考虑ArXiv材料分区**（虽然不如物理普及）

#### 针对医学领域

1. **PMC（PubMed Central）专用下载器**
2. **Europe PMC支持**
3. **bioRxiv预印本优先**

#### 针对低成功率查询

1. **催化剂(18.4%)**: 检查是否关键词过窄，调整检索策略
2. **二维材料(30.8%)**: 考虑添加中文期刊源（中国在该领域领先）
3. **癌症免疫治疗(33.1%)**: 考虑临床试验数据库

#### 通用优化

1. **学科自适应策略**:
   - 天文/计算机: arXiv优先
   - 医学: PMC优先 → Unpaywall
   - 材料: ResearchGate → 机构仓储 → Unpaywall

2. **失败原因分析**: 统计403/404/timeout分布，针对性优化
