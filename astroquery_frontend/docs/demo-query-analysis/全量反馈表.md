## 全局发现（8 条系统规律）

1. **原型天体种群污染**：以类名命名的天体（大陵五/米拉/Vela? 不——Vela 是 DM 对象混淆），文献讲"这一类"时 VLM 分不清目标（大陵五 10/14、米拉 19/23）
2. **语义相近量混淆**：transit_depth vs 谱线吸收深度（53/56）、sync peak vs 监测频率、自转周期 vs 黑子/脉动周期（常陈一 5/9）
3. **对象混淆（跨天体）**：Sirius A/B 组分、Vela 收到 Crab 的 DM（56.77）、SN 2011fe 收到别的星等
4. **字段错配（系统性 bug）**：距离模数值标进 distance 字段（M31 11 条、LMC 18 条）——重查无法修复，需改代码
5. **数据库脏值**：Gaia DR2 负视差（δ Cephei −1.17）、TIC 距离错值（4352 pc）、Gaia 的 WD Teff 不可靠（M57 中心星 8600 K vs 真实 120,000 K）、HD 星等 50 mag
6. **专业符号写作形式**：Ṗ（Pdot）、Δm₁₅ 下标写法 VLM 识别不了——两轮 0 条
7. **查询措辞与文献用语错位**：Her X-1 的"爆发重现时间"vs 文献"超轨道周期"——查询词要贴近文献用语
8. **成功模式**：单天体聚焦论文 + 文献值高度一致（周期/红移/黑洞质量/速度弥散）→ 提取最干净
