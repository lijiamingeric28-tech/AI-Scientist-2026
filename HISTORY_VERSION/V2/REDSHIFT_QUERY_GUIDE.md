# 🌌 红移查询测试指南

**目的**: 测试科学数据管道对红移数据的提取能力

---

## 📝 推荐查询列表

### 1️⃣ 简单查询（最推荐）

```
查找类星体的红移数据
```

**预期结果**:
- 实体: quasar, QSO, 类星体
- 属性: redshift, z值, 红移
- 检索到包含红移测量的论文

---

### 2️⃣ 带条件查询

```
查找红移大于2的类星体
```

**预期结果**:
- 实体: quasar
- 属性: redshift
- 条件: z > 2 或 redshift > 2

---

### 3️⃣ 具体天体查询

```
查找3C273的红移
```

**预期结果**:
- 实体: 3C273 (著名类星体)
- 属性: redshift
- 已知红移: z ≈ 0.158

---

### 4️⃣ 时间限定查询

```
获取2020年后观测的星系红移
```

**预期结果**:
- 实体: galaxy, 星系
- 属性: redshift
- 条件: 年份 ≥ 2020

---

### 5️⃣ 多属性查询

```
查找高红移类星体的红移和光度
```

**预期结果**:
- 实体: high-z quasar
- 属性: redshift, luminosity
- 提取多个字段

## 🎯 成功标准

✅ **管道正常执行**
- 4个子图全部完成
- 无崩溃或错误

✅ **意图正确识别**
- 实体包含 quasar/QSO/类星体
- 属性包含 redshift/红移

✅ **数据成功提取**
- 提取到至少10条以上记录
- 数值格式正确（如 z=2.5, 0.158等）

✅ **质量保证**
- 质量评分 > 0.85
- 数据无重复
- 输入输出记录数一致

## 💡 测试技巧

### 如果论文数量少
- 尝试更通用的查询：`查找星系红移`
- 扩大时间范围：不加年份限制

### 如果提取失败
- 检查 `data/papers/` 是否有PDF
- 查看 `data/reports/` 的提取日志

### 如果质检报错
- 查看控制台的详细错误信息
- 检查LLM API密钥是否配置
