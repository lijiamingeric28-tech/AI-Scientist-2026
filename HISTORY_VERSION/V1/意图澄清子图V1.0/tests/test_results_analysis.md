### 问题与建议

#### 🐛 问题1：T104缺少追问（唯一失败用例）

**现象：**
```
输入："找超新星的数据"
输出：entities=["超新星"], properties=[]
问题：未追问properties
```

**建议修复方案：**

1. **方案A：修改 `generate_schema`**
   - 确保properties字段始终设置为 `required: true`
   - 代码位置：`tools/evaluate_intent/generate_schema.py`

2. **方案B：修改 `check_completeness`**
   - 强制检查：如果properties为空数组，标记为不完整
   - 代码位置：`tools/evaluate_intent/check_completeness.py`

**推荐：** 方案B更直接，避免依赖LLM判断。

---

#### 🐛 问题2：日志文件为空

**原因：**
- 日志配置只对主进程生效
- 子模块（tools、agents）的logger未继承配置

**已修复：** 使用 `logging.basicConfig` 配置根日志记录器，所有模块自动继承。

**验证方式：** 下次测试后检查 `test_logs.log` 文件内容。
