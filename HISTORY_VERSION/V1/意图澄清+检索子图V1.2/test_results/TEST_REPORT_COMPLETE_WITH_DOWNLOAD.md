### 失败原因说明

**1. HTTP 403 - 访问被拒绝**
- 原因: 出版商限制访问（需订阅）
- 示例: Elsevier, Springer, Wiley等商业期刊
- 预期行为: 正常，部分论文需付费访问

**2. No PDF links found**
- 原因: OpenAlex元数据中没有可用的PDF链接
- 可能情况: 
  - 论文确实没有开放获取版本
  - 元数据不完整
- 预期行为: 正常

**3. All sources failed**
- 原因: 尝试了所有可能的来源均失败
- 包括: pdf_url, oa_url, HTML解析等
- 预期行为: 正常，已尽最大努力
