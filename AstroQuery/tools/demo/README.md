# AstroQuery 自动演示脚本 · 第二版（自行录屏）

脚本只自动点击前端，不录制或生成视频。它启动应用自带的 **pywebview / WebView2 内嵌窗口**，不打开独立 Edge，也不显示浏览器地址栏。

## 开始演示

保持后端8781、前端5173运行，双击本目录的 **开始演示.cmd**。

也可在 `AstroQuery/frontend` 执行：

```powershell
npm run demo:tour
```

脚本在首页准备完成后留5秒供你开启录屏，然后开始自动点击。准备期间不再反复打开数据和对话。演示窗口会临时置顶以保证画面可见。演示结束后窗口保留；关闭窗口或按Ctrl+C结束。脚本不会发送新追问、执行科研任务、保存管理表单或发布规范。

鼠标为黑色箭头、白色细边与蓝色光晕，移动带缓入缓出，点击有轻微光效。阅读时移到边缘，避免挡住数值和公式。这些效果只注入本次演示窗口，不修改应用主题。

## 第二版的节奏

每个实际画面单独设置阅读时间，内容加载完成才开始停留，不再把剩余秒数补在章节最后一个界面。已经选中的页签和选项不再重复点击，抽屉关闭后才继续切页。

数据筛选 → 单篇资料 → 同性质对照 → 已保存追问统一围绕 **视线 E(B−V)**；知识管理继续查看同一条颜色与消光知识。页面之间以实际导航和柔和滚动连接。

| 镜头 | 重点停留 | 3分钟剪辑分配 / 精剪 |
|---|---|---|
| 首页、样例目录 | 输入框与星形设置；最新样例身份 | 9秒 / 5秒 |
| 正常回放 | 第一次审核先读原件与测量8秒，再读原选择2秒，提交后观察反馈；其余按历史答案快速继续，每个准确审核版本仅提交一次 | 40秒 / 12秒 |
| 执行明细 | 全景与节点各2.4秒，事件和作业简短浏览 | 9秒 / 4秒 |
| 数据 | 全任务范围→55条E(B−V)测量→选择操作→图像原件 | 16秒 / 7秒 |
| 单篇资料 | 主解读6秒、理解提示3.5秒，另展示引用、测量和来源 | 23秒 / 12秒 |
| 性质对照 | 综合正文5秒、紧凑来源表3.5秒 | 11秒 / 5秒 |
| 质量与处理 | 完成情况、已加载的处理记录、覆盖差异各2秒 | 8秒 / 4秒 |

## 镜头顺序

首页输入框 → 最新样例 → 100倍正常回放 → 执行明细 → 测量与图像 → 单篇资料三个页签 → 性质对照 → 质量与处理 → 已保存的科研追问、引用与参数试算 → 知识图谱/矩阵 → 天体与性质规范 → 系统配色 → 导出面板。

`shots.json` 的 `beats` 是各个画面的实际阅读秒数；`seconds` 与 `edit` 是剪辑参考。`complete.srt` 对应180秒剪辑稿，`edit-86s.srt` 对应86秒精剪参考。**剪辑时间轴不等于脚本实际运行时长**：包括实际页面加载、鼠标移动及完整播放器。第一版实测100倍正常回放约14分钟，第二版仍保留完整播放；自行剪辑时将回放镜头压缩到40秒，并保留首次审核的阅读与确认过程。脚本不跳阶段、不改播放器逻辑。

## 分段展示与快速检查

```powershell
# 只展示追问，准备倒计时8秒
npm run demo:tour -- --chapter followup --countdown 8

# 从执行明细开始，避免重新回放
npm run demo:tour -- --from execution

# 快速检查界面路径，不录屏，完成后关闭本次窗口
npm run demo:tour -- --mode rehearse --from execution

# 按真实阅读节奏检查后半段，完成后自动关闭本次窗口
npm run demo:tour -- --from execution --countdown 0 --exit-on-finish
```

镜头名称：`home`、`gallery`、`replay`、`execution`、`data`、`material`、`comparison`、`quality`、`followup`、`knowledge`、`registry`、`theme`、`export`。

默认诊断输出在 `AstroQuery/scratch/demo-tour-v2-2026-11-14/present`：各镜头截图、`timings.json`实际时间、`beats.json`逐画面阅读时段、`navigation.json`有效页签切换、`requests.json`接口审计和对应字幕。`actual.srt` 按本次真实起止时间生成，可用于对齐原始素材；180秒与86秒字幕用于剪辑。加 `--beat-screenshots` 可保存每个阅读点的截图。使用 `--output` 可更换目录。`--url` 可指定现有服务地址，页面仍在内嵌窗口中打开。
