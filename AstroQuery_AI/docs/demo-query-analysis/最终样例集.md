## 三、三轮验证的规律总结

1. **成功的模式**：单天体聚焦论文 + 文献值高度一致的性质 → 提取最干净（NGC 4151 的 Hβ FWHM、天鹅座X-1 的轨道周期、Capella 的质量）
2. **失败的模式**：① 原型天体种群污染（大陵五/米拉/RR Lyr）；② 语义相近量混淆（transit_depth vs 谱线吸收深度、sync peak vs 监测频率）；③ 性质在文献中以其他名称出现（Pdot、35 天超轨道周期、星风强度、glitch 计数）；④ 数据库值不可靠（Gaia 的 WD Teff）
3. **修复有效**：删坏性质重查后，天狼星B（去 Teff）、LMC（去 distance）、天鹅座X-1（去 companion_mass）、3C 273（去视星等）全部变干净
4. **系统 bug 待修**：距离模数错配（M31/LMC 的 dist_modulus 值标进 distance 字段）、Gaia DR2 负视差未过滤（δ Cephei）
