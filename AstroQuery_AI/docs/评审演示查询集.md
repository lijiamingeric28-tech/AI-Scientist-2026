# 评审演示查询集

> 2026-09-01 设计。方法：每主体先按系统 P1 逻辑（SIMBAD TAP basic.otype → OTYPE_PARENT 双库拼合）确认 otype 与 RAG 库，
> 再按历史查询记录逐性质人工审核提取质量（对照文献真值），只保留"提取值正确且多源一致"的性质。
> 覆盖 SIMBAD 四大类：TAXONOMY OF STARS / SETS OF STARS / TAXONOMY OF GALAXIES / SETS OF GALAXIES。

## 一、历史性质提取质量审核结论（决定选什么性质）

**✅ 提取质量好（值正确、多源收敛）：**
- 天体测量（视差/距离/自行/坐标）：大角星 88.83 mas、比邻星 768.5 mas、Fomalhaut (329.22, -164.67) mas/yr、M45 7.42-7.49 mas、M31 744-784 kpc —— 全部与 Gaia/文献一致
- 光变周期：delta Cephei 5.3663 d（22 条全一致）、RR Lyr 0.5668 d
- 金属丰度 [Fe/H]：大角星 -0.52±0.04（极紧）、M13 -1.45~-1.60、delta Cephei ~0、M45 -0.03~+0.03
- 光谱型 / Teff：Fomalhaut A3V、delta Cephei F5Ib-G2Ib、Pollux K0III、大角星 4286±30 K
- 红移（QSO/AGN）：3C 273 的 0.158（9 条全一致）
- 星团年龄/距离：M45 年龄 112-132 Myr、距离 133-136 pc（还保留了 Hipparcos 争议旧值 118-125 pc，正好展示冲突解决）
- 绝对星等 / X 射线光子谱指数：3C 273 的 -25.7~-26.6、1.66-1.84
- 恒星质量/半径：参宿四 15-20 Msun / 645-1400 Rsun（弥散合理）、Pollux ~1.9 Msun / 8.8-9.3 Rsun

**❌ 提取质量差（污染/失败，演示时避开或换性质）：**
| 主题 | 问题 | 定性 |
|---|---|---|
| 天狼星 | Teff/半径/质量混入 Sirius B 的值（25193 K、0.0086 Rsun、0.978 Msun） | A/B 双星组分混淆 |
| RR Lyrae | 视星等/金属丰度大量提取到"RR Lyr 型变星种群统计/定标公式"而非该星自身值 | 种群污染 |
| 3C 273 sync_peak_freq | 220 条记录绝大多数是射电核 VLBI 光变曲线的观测频率（223-242 GHz），不是 SED 同步峰频率 | 语义错分 |
| 3C 273 gamma_photon_index | 3 条中 2 条是谱指数 α（-2.85）而非光子指数 | 符号混淆 |
| M31 红移 | 0 条记录（蓝移天体论文不引红移） | 该性质文献缺失 |
| M13 质量 | 仅 1 条（4.02e5 Msun，值对但单薄） | 文献稀疏 |

**设计启示：**
1. 稳的性质：视差/距离/自行、周期、[Fe/H]、QSO 红移、光谱型、星团年龄距离、绝对星等
2. 避开的坑：多星系统（组分值互相污染）、"某类变星"作为目标（种群统计污染）、射电监测数据（观测频率被当物理量）
3. 新天体选"文献值唯一确定、论文聚焦该天体自身"的对象

## 四、运行建议

1. 现场演示优先：**#16 后发座星系团**（三库命中+暗物质故事）、**#4 蟹状星云脉冲星**（性质维度最独特）、**#8 昴星团**（申报文档案例，结果最成熟）
2. 每组运行 15-60 分钟，建议提前把 A-D 全跑完，现场用回放+溯源视图展示
3. 历史弱项（M31 红移、3C 273 同步峰、天狼星组分混淆）不要在评委面前裸跑，除非作为"质量管线抓出冲突"的负面教学案例
